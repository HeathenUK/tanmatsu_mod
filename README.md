# Tanmatsu_mod tracker audio player

This player for tracker audio is based on the tanmatsu template provided [here](https://github.com/Nicolai-Electronics/tanmatsu-template).

It can use any of three backends to play back .mod, .xm, .s3m, and .it (except micromod): [libxmp](https://github.com/libxmp/libxmp), [libopenmpt](https://github.com/OpenMPT/openmpt), and [micromod](https://github.com/martincameron/micromod) with the choice of which to compile set in menuconfig. I may ultimately fold back to libxmp alone now that most bugs are squashed and I have plenty of CPU headroom.
